# Pleso

Робоча назва. «Плесо» — тиха ділянка води.

Гра на один дотик: крапля падає у ставок, і хвиля має дійти до всіх латать
достатньо високою, щоб вони розкрилися до пунктирної межі.

## Як відкрити

Відкрийте `index.html` у браузері з підтримкою WebGL2 (Chrome, Safari, Firefox).
Це одна самодостатня сторінка: без залежностей, без збирання, без сервера.

## Керування

| Дія | Клавіша або дотик |
| --- | --- |
| Кинути краплю | клік або дотик по воді |
| Почати рівень із картки | Enter або пробіл |
| Ще раз | R |
| Підказка (три ступені) | H |
| Далі, після перемоги | N |

До кліку видно перегляд хвилі: пунктирні лінії показують, куди вона дійде
одночасно.

## Рівні

1. Відстань
2. Відбиття в еліпсі
3. Мілина і камінь
4. Ставок

Мілини сповільнюють і заломлюють хвилю, береги й каміння її відбивають.

## Як влаштовано

- Фізика: хвильове рівняння зі змінною швидкістю на сітці 120×120, рахується на CPU.
- Малювання: шейдер WebGL2 (дно, заломлення, каустика, відблиски, піна) і 3D-камера.
- Перегляд хвилі: ізохрони, алгоритм Дейкстри за швидкістю хвилі.
- Пороги рівнів підібрані симуляцією в Node.

## Що перевірено

- Усі чотири рівні проходяться з місця третьої підказки (у браузері, на кадрах).
- Фінал проходить усі етапи: сповільнення, камера, повтор кидка, світло, захід сонця.

## Що не перевірено

- Плавність.
- Телефон і дотик.
- Кнопка «Далі» на екрані (клавіша N працює).

## Відомі слабкі місця

- Рівень 2 має дуже малу виграшну зону (близько 1% площі).
- Рівень 3 не показує ефект лінзи чисто.
- Хвилі низькі.

Автоматичних тестів поки немає.
